Pengembang di Indonesia sempat kesulitan membuka GitHub pada Jumat (6/11/2026). Gangguan berlangsung sekitar empat jam sebelum akses kembali normal.

## Penyebab gangguan

Kementerian Komunikasi dan Digital (Komdigi) menjelaskan bahwa gangguan dipicu pemblokiran alamat Internet Protocol (IP). Pemblokiran itu dilakukan atas permintaan sebuah instansi pemerintah untuk menangani indikasi serangan malware yang menyasar jaringannya.

Setelah dicek secara internal, Komdigi menemukan bahwa salah satu alamat IP yang diblokir ternyata juga dipakai oleh layanan GitHub. Akibatnya, akses ke platform pengembangan perangkat lunak itu ikut terdampak di Indonesia.

## Langkah penanganan

Komdigi menyatakan telah melakukan penyesuaian untuk memulihkan akses. Kementerian tidak membuka identitas instansi yang meminta pemblokiran maupun alamat IP yang terlibat. Ke depan, Komdigi akan mengevaluasi proses verifikasi dan pemblokiran alamat IP agar penanganan ancaman keamanan siber lebih tepat sasaran.

## Kenapa ini penting

GitHub dipakai luas untuk menyimpan kode, berkolaborasi, hingga menjalankan proses publikasi situs dan aplikasi. Gangguan beberapa jam saja bisa menghambat pekerjaan banyak developer, mahasiswa, dan startup.
